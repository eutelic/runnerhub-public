RunnerHub Diagnostics

Redacted state and startup evidence for troubleshooting
Dashboard

Support bundle

Collects RunnerHub API state, recent audit events, runtime/listener status, and retained startup diagnostics. Secrets and job output are not intentionally included.

For clean pre-job container exits, set RUNNERHUB_DIAGNOSTICS_ENABLED=true on the agent service so the last 200 startup log lines are captured, redacted, and retained with the failed worker.
