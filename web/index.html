Enable automatic redeploy
The TrueNAS account needs APPS_READ and APPS_WRITE. RunnerHub auto-detects the host path backing its /data mount. The API key is written only to RunnerHub's persistent bootstrap directory and mounted into the standalone deployer as a file-backed secret. The deployer remains a separate TrueNAS app so it survives RunnerHub restarting itself.
